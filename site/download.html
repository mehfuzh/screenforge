Install

  1. Step 1Open the DMGDouble-click the file you just downloaded. A window opens with the app and a shortcut to Applications.
  2. Step 2Drag to ApplicationsDrop ScreenForge on the Applications folder, eject the disk image, launch it from Applications or Spotlight.
  3. Step 3Grant two permissionsOn first launch macOS asks for Screen Recording and Input Monitoring. Both live in System Settings → Privacy & Security. Recording needs the first; automatic zooms, which follow your clicks and typing, need the second.

The app runs without a license. Recording, editing and your first three exports are free; after that, exporting needs a key from the pricing page.

Build from source

ScreenForge is Apache-2.0. With a Rust toolchain and the Xcode command line tools installed:

$ git clone https://github.com/mehfuzh/screenforge && cargo build --release -p studio

The binary lands in target/release/screenforge; scripts/bundle.sh wraps it in an .app. The export gate is ordinary Apache-2.0 code: a source build can remove it. The license exists to fund the signed, notarized download, the CI that produces it and ongoing maintenance.

Install

  1. Step 1Install the packageFrom the folder you downloaded to, run sudo apt install ./screenforge_amd64.deb, or open it in your software center. ffmpeg comes bundled; nothing else to install.
  2. Step 2Share your screenRecording works on X11 and Wayland. On Wayland (GNOME, KDE Plasma) your first recording opens the system's "Share your screen" dialog: pick your screen and click Share. ScreenForge remembers the choice and only asks again for a different monitor. To record a window, pick it on the dialog's Window tab. On Wayland the cursor is part of the video and clicks and keystrokes are not recorded, so automatic zooms and cursor effects are not available there yet.
  3. Step 3LaunchOpen ScreenForge from your app menu, or run screenforge in a terminal. System audio recording is macOS-only for now; the microphone works.
$ sudo apt install ./screenforge_amd64.deb   # Debian / Ubuntu
$ tar xzf ScreenForge-linux-x86_64.tar.gz && ./ScreenForge/screenforge   # other distros
$ systemctl --user restart xdg-desktop-portal   # Wayland: no "Share your screen" dialog? restart the portal
